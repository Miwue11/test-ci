# Test de CI orientativo

Test de cociente intelectual orientativo en 5 secciones (razonamiento abstracto, numérico, verbal, memoria de trabajo y velocidad), con tres versiones: Forma A, Forma B y Orión.

Es un juego, no un test clínico: no está baremado con una muestra real.
